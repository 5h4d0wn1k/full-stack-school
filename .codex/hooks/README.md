# Codex Hooks

This directory contains repo-local preflight and pre-handoff guidance for AI-assisted sessions.

- `preflight.sh` is a manual verification helper. It is not an auto-executed hook.
- `pre-handoff.md` is an advisory checklist for final review before a PR handoff.

Do not add auto-running hooks, deploy hooks, service restarts, or secret-handling scripts without an explicit reviewed change.
